# Kmar Ksentini · Portfolio

Bilingual (French / English) portfolio of Kmar Ksentini, computer engineering student specialising in generative AI, data science and DevOps.

**Live site:** https://mansour4550.github.io/kmar-ksentini-portfolio/

## Features

- FR / EN language switch (remembered per visitor, `#en` link opens English)
- 3D pop-out portrait with mouse parallax
- Three.js robot that unfolds while scrolling and follows the reader through each section
- Detailed project case studies with tilting device mockups
- Responsive layout for phone, tablet and desktop

## Run locally

It is a single static page. Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Stack

HTML, CSS, vanilla JavaScript, [Three.js r128](https://threejs.org/) (loaded from cdnjs), Google Fonts.
